# MSWordMacro

A Microsoft Word VBA Macro to apply Bangla and English fonts easily and efficiently.

## How to Install the Macro in Microsoft Word

Follow the steps below to install and use the macro in Microsoft Word.

### Step 1: Download the Macro File

1. Visit the [MSWordMacro GitHub Repository](https://github.com/prodipalways/MSWordMacro/blob/main/MSWordMacro.bas).
2. Open the `MSWordMacro.bas` file.
3. Click the **Download raw file** button to download the macro file to your computer.

### Step 2: Open Microsoft Word

1. Open Microsoft Word.
2. Press `Alt + F11` to open the Microsoft Visual Basic for Applications (VBA) Editor.

### Step 3: Import the Macro

1. In the VBA Editor, locate the **Project Explorer** window.
2. Select the project where you want to install the macro.
   - To use the macro in the current document, select the document's project.
   - To use the macro in all Word documents, select `Normal` (Normal.dotm).
3. Click **File → Import File**.
4. Browse to the downloaded `MSWordMacro.bas` file.
5. Select the file and click **Open**.

The macro will now be imported into your selected VBA project.

### Step 4: Save the Macro

- If you imported the macro into a document, save the document as **Word Macro-Enabled Document (*.docm)**.
- If you imported the macro into `Normal.dotm`, save the Normal template when prompted to retain the macro for future use.

### Step 5: Run the Macro

1. Return to Microsoft Word.
2. Press `Alt + F8` to open the Macro dialog box.
3. Select the desired macro.
4. Click **Run**.

The macro will execute in Microsoft Word.

## Important Notes

- Microsoft Word Desktop is required.
- Macro functionality may not be available in Word Online.
- Only import macros from trusted sources.
- Do not enable all macros globally. Follow your organization's macro security policy.
